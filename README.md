# 미니단어장 영단어 암기 앱

수능연계 영단어 암기 앱을 기반으로 만든, **미니단어장(Unit 01~15, 총 550단어)** 전용 암기 웹앱입니다.
설치나 서버 없이 `index.html` 파일만 열면 바로 동작합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 화면(설정/문제풀이/결과)과 로직이 모두 담긴 메인 파일 |
| `words.js` | 단어 데이터 (`words` 배열) + Unit 제목 (`unitTitles` 객체) |

두 파일은 **반드시 같은 폴더**에 있어야 합니다. `index.html`이 `<script src="words.js">`로 데이터를 불러옵니다.

## 사용 방법

1. `index.html`을 브라우저(모바일/PC 모두 가능)로 엽니다.
2. 설정 화면에서 아래 항목을 입력합니다.
   - **범위 선택 방식**: 드롭다운에서 아래 둘 중 하나 선택
     - `Unit 번호로 선택` → 선택 시 Unit 시작~끝 번호 입력칸만 활성화 (예: 1~3 → Unit 1·2·3의 단어 전체가 출제 범위)
     - `단어 번호로 선택` → 선택 시 단어 번호(1~550, Unit 순서대로 이어진 연속 번호) 시작~끝 입력칸만 활성화 (예: 100~150)
     - 하나를 선택하면 다른 하나의 입력칸은 자동으로 비활성화됩니다.
   - **문제 수**: 10~100개 (범위 내 단어 수보다 많으면 자동으로 조정)
3. **시작하기**를 누르면 문제 풀이가 시작됩니다.

## 문제 유형 (매 문제마다 무작위 출제)

| 유형 | 뱃지 | 방식 |
|---|---|---|
| ① 단어 맞추기 | 한글 뜻을 보고 영단어 4지선다 |
| ② 뜻 맞추기 | 영단어를 보고 한글 뜻 4지선다 |
| ③ 빈칸 채우기 | 단어 중간 일부가 빈칸(`_`) 처리, 빈칸 알파벳을 순서대로 직접 입력 |
| ④ 직접 입력 | 한글 뜻을 보고 영단어 전체를 직접 입력 |

- 오답 시 1회 재도전 기회가 주어지고, 두 번 모두 틀리면 정답 공개 후 다음 문제로 넘어갑니다.
- 4지선다 유형은 대소문자 구분 없이 정확히 일치해야 정답 처리됩니다.

## 결과 화면

- 첫 시도 정답 / 두 번째 시도 정답 / 두 번 모두 틀림 통계와 전체 정답률을 보여줍니다.
- 두 번 모두 틀린 단어는 하단 복습 목록에 정리됩니다.
- **같은 설정으로 다시 풀기**: 직전에 선택했던 모드(Unit/번호)와 범위 그대로 새 문제를 출제합니다.
- **처음으로**: 설정 화면으로 돌아가 범위를 다시 지정합니다.

## 단어 데이터 구성 (`words.js`)

```js
const words = [
  { num: 1, unit: 1, eng: "complain", kor: "항의하다, 불만을 털어놓다" },
  ...
  { num: 550, unit: 15, eng: "attention", kor: "주의(집중)" },
];

const unitTitles = {
  1: "글의 목적 찾기",
  2: "글의 심경·분위기 파악하기",
  ...
  15: "알맞은 어법·어휘 찾기",
};
```

- `num`: 전체 550개 단어에 매긴 연속 번호 (Unit 01 → 15 순서)
- `unit`: 해당 단어가 속한 Unit 번호 (1~15)
- `eng` / `kor`: 영단어와 한글 뜻

## 단어 데이터를 바꾸거나 추가하고 싶다면

`words.js`의 `words` 배열에 `{ num, unit, eng, kor }` 형식으로 항목을 추가/수정하면 됩니다.
- `num`은 중복 없이 이어지는 정수여야 "단어 번호로 선택" 범위가 정확히 동작합니다.
- `unit`을 새로 추가하는 경우 `unitTitles`에도 해당 번호의 제목을 함께 추가해 주세요(제목은 현재 화면 표시에는 쓰이지 않지만, 추후 기능 확장 시 활용할 수 있습니다).

## 기술 스택 / 특징

- 순수 HTML + CSS + JavaScript (프레임워크·빌드 과정 없음)
- 외부 네트워크 요청·로컬 저장소(localStorage 등) 미사용 — 새로고침 시 진행 상황은 초기화됨
- 모바일 우선 반응형 레이아웃 (최대 너비 480px 중앙 정렬)
